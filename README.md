## Murshid

**Learn something useful. Find your next step.**

Murshid connects short-form learning with mentors, communities, events, and
opportunities, so a useful idea can lead to a conversation or an action.

The MVP includes:

- **Learning and discovery:** short-form content, saved resources, and an
  opportunity directory.
- **Guidance and participation:** mentor booking, session preparation,
  communities, and event registration.
- **Platform operations:** an operator console for review, moderation,
  curation, and access management.

Arabic and English, including right-to-left layouts, are part of the
product's foundation.

## Behind the product

The implementation spans a React Native / Expo mobile app, a Next.js
operator console, and a Postgres backend with Supabase. TypeScript connects
the applications through shared database types.

Engineering priorities include server-side authorization, feature-level
tests, bilingual interface checks, and repeatable local verification.
